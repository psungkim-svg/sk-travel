📋 여행 요약

⚡ 빠른 실행

✈️ 비행기

아래 버튼을 톡 누르면 우리 비행기가 한 번에 들어와요.

🌟 사용법

1️⃣ 비행기 버튼을 톡 누르면 끝!

2️⃣ 일정은 날짜를 톡 눌러서 봐요. 고치면 자동 저장돼요.

3️⃣ 서류는 🧳 준비 탭의 👜 서류함에 위치와 링크만 적어두세요.

📸 일정표 사진

종이 일정표 사진을 보기용으로 띄워요. 사진은 저장되지 않아요. 일정으로 옮기려면 아래 📥 일정 가져오기를 쓰세요.

📥 일정 가져오기

① 아래 버튼으로 요청문을 복사해서, 클로드에 일정표 사진과 함께 붙여넣으세요.
② 클로드가 만든 HTML 결과를 아래 칸에 붙여넣고 미리보기를 누르세요. 화면에는 날짜별 드롭다운으로 나타나고, 저장 후 그대로 고칠 수 있어요.

📅 날짜별로 보기

날짜를 톡 누르면 펼쳐져요. 고치면 자동으로 저장돼요 💾

📝 방문 기록

간 곳, 먹은 곳을 별점과 메모, 사진으로 남겨요.

🏨 숙소 (택시기사에게 보여주기)

🗺️ 공항 → 호텔 길 찾기

호텔을 적고 버튼을 톡 누르면 구글맵이 열려요.

누르면 구글맵이 열리고 실시간 길안내가 시작됩니다. API 키 불필요.

🏠 집 → 공항 길 찾기

출발지:

✈️ 공항 안내

공항 이름을 누르면 펼쳐져요.

공항 정보는 출발 전 공식 사이트에서 다시 확인하세요.

👜 서류함

여권 번호나 여권 사진은 여기에 넣지 마세요. 서류가 있는 위치와 링크만 저장하세요. 원본은 구글 드라이브 비공개 폴더에 보관합니다.

🧳 준비물 체크

섹션을 톡 눌러 펼치고, 체크하면 자동으로 저장돼요 ✅
