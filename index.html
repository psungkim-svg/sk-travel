SK-Travel Update v7 · 최소 체험본

User Trial / Working Baseline · 최종 제품 아님 · GitHub Pages에서 핵심 흐름 확인용

포함 기능: JSON/CSV 일정 가져오기, 장소별 가이드 연결·검토, 방문 진행, 사진, 범용 ZIP 백업/복원. 간소화: OCR·Office 문서 변환, GPS, 오프라인 PWA 설치 화면은 제외했습니다. 위치는 저장하지 않습니다. 이 체험본은 HTTPS GitHub Pages에서 실행하세요.

1. 여행 선택

2. 일정 가져오기

JSON(`sk-travel-itinerary` 또는 v3 일정) 또는 표 형식 CSV만 지원합니다. 미리보기와 확인 후 새 여행으로 저장하며 기존 여행은 바꾸지 않습니다.

3. 오늘 순서 · 다음 장소

여행을 선택하거나 합성 예시를 만들어 주세요.

4. 장소별 가이드 가져오기

장소를 직접 선택합니다. 가져온 가이드는 새 검토 필요 버전으로 저장되고, 현재 안내로 활성화하는 것은 별도 확인입니다.

가이드가 선택되지 않았습니다.
버전 검토 및 활성화

5. 선택한 장소의 사진

사진 원본을 선택한 stop에 명시적으로 연결합니다.

6. 범용 백업 / 복원

선택한 한 여행을 ZIP으로 저장합니다: trip-data.json, PDF 보고서, CSV, 원본·사진, 스키마와 SHA-256 manifest. 복원은 항상 새 여행 사본을 만듭니다. PDF/A 인증은 아닙니다.

브라우저 로컬 저장소만 사용합니다. 공개 GitHub 저장소에 개인 일정·백업·사진을 커밋하지 마세요. 오프라인 동기화, 라이브 관광 정보, 백그라운드 GPS는 제공하지 않습니다.
