# SK 여행 · 현장 가이드 시험용 v0.1.0

## GitHub Pages에 올리기

ZIP을 **압축 해제한 뒤** `index.html`, `app.js`, `sw.js`, `manifest.json`, `packing.html`, `spain-trip-data.json`, `icons/` 폴더를 같은 디렉터리에 업로드합니다. ZIP 자체를 업로드하거나 `sk-travel-app/` 폴더가 한 단계 더 생기면 주소가 달라집니다. 저장소 Settings → Pages에서 해당 브랜치/폴더를 선택하고 배포 주소의 `index.html`을 엽니다. HTTPS에서 설치/PWA·GPS가 동작합니다. 기존 v3/v4 앱 주소에 바로 덮어쓰지 말고 **새 저장소 또는 새 경로에서 시험**하세요. 이 앱은 기존 앱의 저장 데이터를 자동 이전하지 않습니다.

## 이 버전에서 실제로 되는 것

- 기존 스페인 예시 JSON을 첫 실행 시 가져와 날짜별 일정·항공·숙소 일부를 표시합니다. **원본의 모든 세부 메타데이터를 보존하는 마이그레이션은 아닙니다.** 예시 날짜 2026-10-22~31은 현재 기준 과거입니다.
- 최대 4개 여행, 한 여행 선택, 텍스트/TXT/MD 및 `sk-travel-trip` JSON의 기본 일정 가져오기, 저장 전 전체 화면 검토, 날짜별 일정 편집, 홈·일정·항공의 동일 데이터 표시, 이전/다음 한 칸씩 이동, 10분 후 현재 예정 일정 복귀, 완료 상태.
- 실제 사진 1~3장 직접 첨부, 별도 현장 가이드 편집, 확정 일정 ID를 담은 AI 요청문 복사/저장, AI 결과 `sk-guide-v1` JSON 개별 승인. 외부 사진 URL은 자동 다운로드하지 않습니다.
- 리허설 현지 시각, 현재 날씨(Open-Meteo, 좌표 입력 시), 위치 권한 요청과 정확도 표시. 준비물 탭은 첨부받은 `packing.html`을 재사용합니다. 선택 여행별 체크 분리 기능을 연결합니다.
- 전체/여행별 JSON 파일 백업과 복원. 휴대폰에서는 다운로드 파일을 사용자가 직접 Google Drive로 옮기고, Drive 파일은 Android 파일 선택기에서 고를 수 있는지 기기별로 확인하세요.

## 아직 제공하지 않는 기능 — 반드시 읽어 주세요

- PDF/이미지 OCR 자동 추출, Google Drive 자동 로그인·업로드·보관 목록, AI ZIP 자동 해제·사진 삽입, GPS 주변 관광지/화장실 검색, 항공사 실시간 상태는 **미구현**입니다. 입력 화면에서도 숨기지 않고 안내합니다.
- 스페인 JSON의 상세 가이드·좌표·원본 첨부 내용을 모두 변환하지 않습니다. 원본 파일의 실제 개인 정보와 예약 정보를 공개 GitHub에 올려도 되는지 배포 전 반드시 검토하세요.
- 여행 정보와 사진은 브라우저 localStorage에 저장되므로 사진이 크면 용량 부족으로 저장되지 않을 수 있습니다. 작은 사진 사용 및 자주 백업하세요. 이 백업은 **암호화되지 않습니다**. 브라우저 데이터 삭제·도메인 변경 시 데이터가 사라질 수 있습니다.
- AI 가이드의 출처와 실제 사진 여부는 앱이 자동 확인하지 않습니다. '승인' 전 사용자가 확인해야 합니다. 티켓·항공편·화장실 요금·입구는 공식 자료로 재확인하세요.
- 리허설은 시각만 가상화합니다. 시간 판정은 현지 시간 기반이며 실제 완료 여부와 다릅니다. 일정 시간이 없는 경우 자동 현재 단계 판정의 정확도가 떨어집니다.
- 실제 휴대폰·OAuth·오프라인 갱신에 대한 실기기 검증은 아직 하지 않았습니다. 중요한 여행의 단일 정보원으로 사용하지 마세요.

## 기본 조작

관리 → 새 여행 가져오기 → 전체 화면 검토·수정 → 여행 저장. 관리 → 현장 가이드에서 AI 요청서를 복사해 다른 AI에 전달하고, 결과 JSON을 파일로 저장해 `가이드 JSON 가져오기`에서 일정별 승인합니다. 관리 → 가이드 직접 편집에서 실제 사진을 추가합니다. 리허설은 관리의 독립 카드에서 실행하며 홈에서 즉시 종료할 수 있습니다. 사용 후 전체 백업을 내려받아 Drive에 별도로 보관하세요.

## v0.1.2 수정 (덮어쓰기 전 필독)

- `전체 화면에서 일정 검토` 버튼이 반응하지 않던 입력값 수집 오류 수정. 여행 이름·시작일·통화 입력란을 가져오기 첫 화면에서 제거하고 **검토 화면에만** 배치했습니다. 원문의 날짜·지명에서 추정하는 부분은 반드시 직접 확인하세요.
- 기존 `packing.html` 긴 누르기 드래그의 주변 항목 FLIP 애니메이션을 제거하고 놓을 위치 표시를 강조했습니다. 휴대폰 터치감은 실기기에서 확인이 필요합니다.
- 본문 기본 글씨를 키우고 관리 → 글자 보기 설정에서 제목·소제목·본문·자간을 조절하게 했습니다. 관리 맨 아래 버전 확인을 추가했습니다. `version.json`을 함께 업로드해야 합니다.
- Android 뒤로가기는 화면 탭/편집 모달을 이전 기록으로 되돌리도록 처리했습니다. 휴대폰 브라우저에서 다시 시험해 주세요.
- **PDF/이미지 자동 추출은 이 버전에서도 아직 불가능합니다.** 해당 기능을 구현했다고 주장하지 않습니다. 웹 텍스트 또는 TXT/MD/지원 JSON으로 먼저 시험해 주세요. 웹 자유 형식 텍스트는 모든 여행 항목을 정확히 분류하지 못합니다.
- GitHub에 덮어쓸 때 `app.js`, `sw.js`, `version.json`과 다른 루트 파일을 모두 업로드하고, 캐시 갱신에 시간이 걸릴 수 있습니다. 업데이트 전 기존 앱에서 백업하세요.

## v0.1.3 변경 및 제한
- 상단 브랜드 한 줄, 여행 선택 버튼 축소. AI 요청문·일정 원문 입력칸을 휴대폰 전체 화면에 가깝게 확대.
- 일정 탭은 첨부 원본 `schedule-seed.html`의 **색상·날짜 바·안내문 아코디언 형태**를 바탕으로 한 `schedule-view.html`을 사용합니다. 모든 기존 안내문 제목을 유지하며 정보가 없으면 ‘입력된 정보 없음’으로 표시합니다. 스페인 예시 날짜별 바 제목은 원본 제목을 유지합니다. **원본 일정의 모든 표·본문 내용을 그대로 복사한 것은 아닙니다**. 다른 여행은 해당 날짜/도시 제목을 사용합니다.
- 준비물 항목을 옮기는 동안 다른 항목의 위치를 바꾸지 않고 놓을 대상만 강조한 뒤 손을 뗄 때 이동합니다. 실제 Galaxy 터치 조작 검증은 아직 필요합니다.
- 백업을 누르면 ‘기기에 다운로드’ 또는 ‘공유 메뉴 열기’를 선택합니다. 공유 메뉴에서 Drive 앱을 고를 수 있는지 기기마다 다릅니다. **웹앱은 사용자의 Drive 폴더에 파일을 직접 쓰지 않습니다.** 공유가 안 되면 다운로드 후 파일 앱에서 Drive로 업로드하세요.
- `schedule-view.html`, `version.json`, `sw.js`, `app.js`, `packing.html`을 포함해 ZIP 속 모든 파일을 함께 덮어올리세요.

## v0.1.4 원본 화면 우선
- 홈 맨 위 세 칸의 레이아웃·폰트 크기·색상·높이를 첨부받은 v4.2.1 `index.html`의 `.home-top-board`, `.top-cell`, `.top-label`, `.top-value`, `.top-sub` 스타일에서 가져왔습니다. 시간은 선택한 여행의 시간대에 따라 갱신하며 날씨 값은 이 시험 앱의 Open-Meteo 현재 온도만 표시하므로 **원본 날씨 상세 기능까지 동일한 것은 아닙니다**.
- 일정 화면은 첨부 `schedule-seed.html`의 CSS와 날짜별 바·문서 안내 바를 따릅니다. 사용자 글자 크기 설정이 일정 화면의 원본 크기를 바꾸지 않습니다. **원본 내용 전체의 1:1 재현은 아직 아닙니다.** 기존 스페인 여행의 날짜별 제목과 모든 문서 바 제목을 유지하되, 내용은 현재 여행 데이터에서 생성하고 값이 없으면 비었다고 표시합니다.
- 준비물 드래그 중 자리표시자 높이 변화와 브라우저 스크롤 앵커링을 줄이고, 이동 중 대상만 표시합니다. 손을 뗀 뒤 바뀐 위치의 주변 항목에 280ms 정착 애니메이션을 적용합니다(동작 감소 설정에서는 없음). 휴대폰 실기기에서 여전히 흔들리는지 재확인이 필요합니다.
