# SK-여행 v4.1.1 — 통합 시험본

이 디렉터리는 v3.10.0 기반의 별도 통합 작업본입니다. 기존 배포 파일을 덮어쓰지 않습니다. 이 빌드는 아직 배포 승인을 받지 않았습니다.

## 실행

정적 웹서버에서 이 폴더를 서비스하세요. `index.html`, `packing.html`, `spain-trip-data.json`, `schedule-seed.html`, `manifest.json`, `sw.js`, `version.json`, `icons/`를 같은 경로에 두어야 합니다. HTTPS 또는 localhost에서 PWA·위치·Google OAuth를 사용할 수 있습니다.

## 여행/자료 가져오기

- 관리 → **일정 사진에서 만들기**: 사진을 OCR한 뒤 인식 텍스트를 수정하고 날짜/일정을 검토합니다. OCR 초안은 자동으로 사실 확인된 예약 정보가 아닙니다.
- 관리 → **텍스트로 만들기**: 여행 이름·시작일과 날짜가 포함된 텍스트를 입력하고 변환 결과를 검토합니다.
- 일정 JSON 가져오기는 기존 v3 호환 JSON과 `sk-travel-trip` 패키지를 지원합니다.
- 새 여행을 적용하기 전 미리보기에서 백업 선택을 확인할 수 있습니다.
- 보강 텍스트/사진은 관리에서 일정 항목을 직접 골라 연결할 수 있습니다.
- 보강자료 JSON 및 이미지 ZIP 예시는 `보강자료-형식.md`를 참고하세요. JSON의 `tripId`는 관리 화면에 표시된 현재 여행 코드와 정확히 같아야 하고, 각 `eventId`는 현재 일정에서 고유하게 일치해야 합니다.
- JSON 패키지에서 `eventId`가 빠졌을 때 임시 생성 코드는 날짜/일자 순서/항목 순서를 바탕으로 만듭니다. 일정을 크게 바꾸면 코드가 달라질 수 있습니다. 여러 번 보강자료를 넣을 여행이라면 원본에 고유하고 지속적인 `eventId`를 명시하세요.

## 준비물 편집

‘여행 1주일 전/3일 전/하루 전/떠나는 날/여행 종류별’ 시점 섹션은 고정입니다. 펼친 목록 안에서 개별 준비물을 추가할 수 있습니다. 각 항목 오른쪽의 작은 **×**를 누르면 취소/삭제 확인 상자가 뜹니다. 항목을 손가락으로 길게 누른 뒤 끌어 다른 목록이나 순서에 놓아 이동합니다. 목록 내용과 이동/삭제는 공통 템플릿에 반영되고, 체크 상태만 여행마다 따로 저장됩니다.

## 리허설 및 현장 주의

관리의 **현장 리허설 시각**은 앱 내부 시각만 바꿉니다. 기기 시계를 바꾸지 않고, 리허설 배너를 표시하며, 실시간 날씨·환율 조회와 위치 추적을 중단합니다. 실제 장기 예보로 표시하지 않습니다.

실시간 날씨·환율·장소/지도 서비스는 인터넷과 외부 제공처의 상태에 따라 달라집니다. Google Drive 연결은 OAuth client 설정이 필요하며, 실제 배포 주소에서 로그인·백업·복원 테스트를 마쳐야 합니다.

## 시험 기록

검증 범위와 남은 제한은 `작업-현황.md`를 확인하세요. 합성 스위스 일정은 사용자 실제 일정의 검증 자료가 아닙니다. 사용자가 제공할 실제 스위스 일정은 아직 이 빌드에서 시험하지 않았습니다.
