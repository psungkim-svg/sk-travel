# SK-여행 v4.2.0 — 최종사용용 앱 빌드

이 폴더는 v3.10.0과 기존 production 위치를 덮어쓰지 않는 독립 앱 빌드입니다. 최종사용을 목표로 앱 화면을 정리했으며 실제 Galaxy 기기 검증과 production 교체는 아직 완료되지 않았습니다.

## 실행

정적 웹서버에서 이 폴더를 서비스하세요. `index.html`, `packing.html`, `spain-trip-data.json`, `schedule-seed.html`, `manifest.json`, `sw.js`, `version.json`, `icons/`를 같은 경로에 두어야 합니다. HTTPS 또는 localhost에서 PWA·위치·Google OAuth를 사용할 수 있습니다.

## 여행 선택과 자료 불러오기

- 홈 상단 설정 아이콘 옆의 라운드 **여행 선택** 버튼을 누르면 이미 기기에 저장된 여행 목록만 나타납니다. 여행을 고르면 홈·일정·항공·준비물 화면이 그 여행으로 전환됩니다. 현재 Spain 한 개라면 Spain 하나만 보이며, 새 여행을 추가한 뒤부터 선택 항목이 늘어납니다. 관리에는 저장된 실제 여행 수와 각 여행별 전환/기기 제거 컨트롤이 표시됩니다.
- 관리 → **여행 일정 텍스트 붙여넣기**를 열어 전체 내용을 한 칸에 붙여넣습니다. `[여행 정보]`, `[일정]`, `[항공]`, `[공항 이동]`, `[공항 안내]`, `[숙소]`, `[티켓]` 표식이 있으면 구역을 분류합니다. 별도의 이름/날짜/도시 입력 칸은 없습니다. 미리보기에서 여행 이름·날짜와 빨간색 예외를 확인하고 저장하면 새 여행 카드가 만들어집니다.
- 날짜별 원 일정은 일정 탭의 아코디언에 표시됩니다. 날짜가 분명한 항공편 출발·도착은 해당 날짜에 이동 일정으로도 표시하고 항공 탭에 상세를 보존합니다. 체크인 날짜가 명확한 숙소는 날짜 아코디언에 요약하며 숙소 탭에도 상세가 있습니다. 정보가 날짜와 분명히 연결되지 않으면 억지로 특정 날짜에 붙이지 않습니다.
- 새로 가져온 일정은 기본적으로 읽기 전용입니다. 일정에 실제 변경이 생긴 경우에만 일정 탭에서 **실제 일정 변경 반영**을 선택해 수정하세요.
- 준비물 7번 여행용 메모에서 기존 메모 제목(예: 공항 복장)을 두 번 누르면 그 메모 아래에 해당 여행만의 추가 메모를 입력할 수 있습니다.
- 항공 탭의 하위 메뉴에서 항공, 공항 안내, 공항↔숙소 이동, 호텔을 확인합니다.
- 일정 JSON 가져오기는 기존 v3 호환 JSON과 `sk-travel-trip` 패키지를 지원합니다.
- 새 여행을 적용하기 전 미리보기에서 백업 선택을 확인할 수 있습니다.
- 보강 텍스트/사진은 관리에서 일정 항목을 직접 골라 연결할 수 있습니다.
- 여행 일정에 맞춰 AI가 만든 설명과 사진은 **AI 보강자료 ZIP 불러오기**에서 추가합니다. ZIP 안에는 `보강자료.txt`와 사진 파일을 넣습니다. 각 텍스트 항목에는 `날짜`, `도시`, 원 일정과 맞는 `일정`, `제목`, `내용`, `사진`(ZIP 안 경로), `출처`, `확인일`, `확실도`를 씁니다. 자료 블록은 `---` 한 줄로 나눕니다. 앱이 날짜·도시·일정 이름으로 연결하며, 유일하게 매칭되지 않는 자료는 보류합니다. JSON이나 내부 코드는 일반 사용자가 작성할 필요가 없습니다.
- AI에게 보낼 ZIP 안내도 관리의 **AI 요청 형식 복사** 버튼으로 복사할 수 있습니다. 보강자료는 안정적인 일정 ID에만 연결하며, 홈에서 이전·현재·다음 일정을 선택할 때 해당 일정의 사진과 정보가 표시됩니다. 사진은 항상 설명보다 먼저 나옵니다. 모호한 연결은 적용하지 않고 관리에서 확인하도록 보류합니다. ZIP 파일 선택기는 Android 파일 선택기를 엽니다. Drive가 파일 제공 위치에 나타나는지는 실제 Galaxy에서 확인이 필요합니다.
- 홈은 필라델피아 시각·여행지 현지 시각/날짜·날씨를 맨 위에 한 번 표시하고, 그 아래 위치 상태, 선택한 일정의 보강자료를 둡니다. 출발 전에는 일정 버튼 위에 준비 카드를 표시합니다. 일정 탭의 원 일정은 보강자료 연결만으로 변경되지 않습니다.

## 준비물 편집

‘여행 1주일 전/3일 전/하루 전/떠나는 날/여행 종류별’ 시점 섹션은 고정입니다. 펼친 목록 안에서 개별 준비물을 추가할 수 있습니다. 각 항목 오른쪽의 작은 **×**를 누르면 취소/삭제 확인 상자가 뜹니다. 항목을 손가락으로 길게 누른 뒤 끌어 다른 목록이나 순서에 놓아 이동합니다. 목록 내용과 이동/삭제는 공통 템플릿에 반영되고, 체크 상태만 여행마다 따로 저장됩니다.

## 리허설 및 현장 주의

관리의 **현장 리허설 시각**은 앱 내부 시각만 바꿉니다. 기기 시계를 바꾸지 않고, 리허설 배너를 표시하며, 실시간 날씨·환율 조회와 위치 추적을 중단합니다. 실제 장기 예보로 표시하지 않습니다.

실시간 날씨·환율·장소/지도 서비스는 인터넷과 외부 제공처의 상태에 따라 달라집니다. Google Drive 연결은 OAuth client 설정이 필요하며, 실제 배포 주소에서 로그인·백업·복원 테스트를 마쳐야 합니다.
