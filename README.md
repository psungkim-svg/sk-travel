# SK-여행 v3.11.0 — GitHub Pages 배포용

정적 웹앱입니다. GitHub Pages 저장소의 최상위(root)에 이 폴더 안의 파일과 `icons/` 폴더를 올리면 실행할 수 있습니다.

## GitHub Pages에 배포하기
1. GitHub 저장소를 만들고 이 폴더 안의 **모든 파일과 폴더**를 저장소 최상위에 올립니다. ZIP 파일 자체만 저장소에 올리는 것이 아니라, 먼저 압축을 풀고 그 안의 파일들을 올려야 합니다.
2. `Settings → Pages`에서 `Deploy from a branch`, `main`, `/(root)`를 선택해 저장합니다.
3. HTTPS 배포가 완료되면 표시된 주소에서 앱을 엽니다. 홈 화면 설치(PWA)는 HTTPS 주소에서 사용할 수 있습니다.

## 포함·제외 자료
- `packing.html`은 요청에 따라 원본 체크리스트와 메모를 그대로 포함합니다.
- 개인 여행 일정/예약 데이터 파일은 포함하지 않았습니다. 새 여행 자료는 실행 후 앱 안에서 가져옵니다.
- 저장 백업 파일과 브라우저의 로컬 저장 내용은 저장소에 포함하지 않습니다.

**공개 저장소는 체크리스트를 누구나 읽을 수 있습니다.** 원본에 집·보안·물품 보관 관련 메모가 있으므로, 공개 범위를 확인한 뒤 직접 업로드하세요.

## 기능 및 개인정보 처리
- AI 조사 요청서는 앱에서 만들고, 앱이 외부 AI를 호출하거나 일정 파일을 전송하지 않습니다. 여행 이름과 예약·여권·승객 정보는 요청서에서 제외합니다.
- AI 결과 ZIP은 브라우저 안에서 검사·미리보기합니다. TXT/MD 및 JPG/PNG/WEBP만 지원하며, 관광지 일정 연결과 각 가이드 이미지 1~3장 연결을 사용자가 확인한 뒤 선택된 여행에 새로 추가합니다. 기존 가이드는 덮어쓰지 않습니다. HTML·스크립트 실행, 경로 탈출, 암호화/손상된 ZIP은 허용하지 않습니다.
- 일정 텍스트·PDF·사진은 새 일정 후보로 미리 보여주며, 사용자가 확인한 뒤에만 충돌 없는 항목을 추가합니다. 날짜/시간은 원문에 없으면 추측하지 않습니다. PDF/사진 OCR은 사용자가 동의한 때에만 OCR 엔진을 공개 CDN에서 내려받으며, 파일은 이 기기에서 처리됩니다. 인식 결과는 반드시 검토·수정하세요.
- 날씨·환율의 외부 조회는 기본 꺼짐입니다. 설정에서 별도로 허용할 수 있습니다. OpenStreetMap 장소 조회는 사용자가 직접 요청하고 좌표 전송 확인에 동의한 경우에만 진행됩니다. Google Drive는 사용자가 연결을 설정하고 백업/복원을 누를 때 사용됩니다.

## 자체 점검 결과와 알려진 제한
- JavaScript/JSON 문법, 파일·아이콘·버전 정합성, 체크리스트 원본 일치, 민감 자료 제외를 검사했습니다. ZIP 파서의 정상/손상/경로탈출 사례, 요청서 개인정보 필터, 일정 충돌·미기재 연도 처리, 저장 용량 실패 시 원복을 합성 데이터로 시험했고 로컬 HTTP 정적 파일 9개가 정상 응답했습니다.
- 실제 GitHub Pages 배포나 브라우저·휴대폰 전체 UI 상호작용은 이 환경에서 실행하지 못했습니다. OCR/CDN·공개 날씨 조회 네트워크도 테스트 과정에서는 실행하지 않았습니다.
- ZIP 입력은 텍스트 파일과 이미지 연결을 중심으로 지원합니다. 임의의 JSON/HTML 실행은 지원하지 않습니다.
- PDF/사진 OCR은 글자 인식 오류가 날 수 있으며 자동 반영하지 않습니다.
- 준비물 체크리스트의 원본 항목 순서 편집은 포함되지 않았습니다.
- 앱은 정적 검사 및 로컬 파일/HTTP 검사를 거쳤습니다. GitHub 계정에 직접 배포하거나 실제 기기에서의 전체 상호작용 회귀 테스트를 수행한 것은 아닙니다.
